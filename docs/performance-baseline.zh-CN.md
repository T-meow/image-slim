# image-slim 性能基线

## 环境

- 日期：2026-07-21
- 系统：Windows 11 专业版 10.0.26200
- CPU：AMD Ryzen 7 9800X3D，8 核 16 线程
- 内存：31.2 GiB
- Rust：1.96.0
- 构建：release，`opt-level = 3`、LTO、单 codegen unit

## 方法

运行命令：

```powershell
cargo test --release --manifest-path src-tauri/Cargo.toml `
  codecs::tests::records_twelve_and_forty_eight_megapixel_baselines -- `
  --ignored --nocapture --test-threads=1
```

测试使用固定算法生成 4000×3000（12MP）和 8000×6000（48MP）RGBA 样本，再分别编码为
PNG、JPEG 和 WebP 源文件。表中时间只包含 `compress` 的编码、元数据处理和结果验证，不包含
样本生成、源文件初次编码、磁盘 I/O 或 release 编译。合成图案较容易压缩，因此该数据适合作为
同机回归基线，不代表真实照片的绝对耗时或压缩率。
