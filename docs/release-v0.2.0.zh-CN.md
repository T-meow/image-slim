# image-slim 0.2.0

新增完全离线的音频压缩：可将图片和音频混合加入同一批次，把支持的音频压缩为兼容性较好的 MP3。安装版、便携版和 Agent 均包含音频编解码器，运行时无需安装 FFmpeg。

## 新增与改进

- 支持 MP3、PCM WAV、FLAC、M4A（AAC-LC/ALAC）和 Ogg Vorbis 输入，输出 MP3；提供 192 / 128 / 64 kbps 三档，默认 128 kbps。
- 音频始终保存到子文件夹并保留源文件；候选文件没有更小时不生成新文件。输出前重新解码并检查时长、声道及源文件变化。
- 音频面板显示时长、采样率和声道，支持试听原文件与已保存结果；批处理时暂停试听。
- 队列支持搜索、状态筛选、体积/节省排序、仅重试失败、清除已完成和累计结果摘要。
- 改变设置保留已完成结果；重新处理时先扫描，取消或扫描失败保留原任务。修复重试丢行和图片对比预览，支持直接拖动分界线、键盘调整及缩放。
- Agent 增加可选 `audio_bitrate_kbps` 参数和 `core.audio` 能力信息，保持现有图片请求兼容。

## 下载

- `image-slim_0.2.0_x64-setup.exe`：Windows x64 安装版，包含 GUI 与 Agent。
- `image-slim_0.2.0_x64-portable.exe`：免安装 GUI 单文件。
- `image-slim-agent_0.2.0_x64.exe`：独立 JSON CLI / MCP stdio Agent。
- `SHA256SUMS.txt`：发布文件 SHA-256 校验清单；附件同时包含项目许可与第三方许可。

## 支持范围

音频输出为有损 MP3，移除标签及封面；支持单声道/双声道、8–192 kHz 输入，最长 6 小时、单文件最大 512 MiB。编码器可能按码率调整输出采样率。不支持 DRM、多声道或 Opus；部分源编码可能无法在内置播放器试听，但仍可转换为 MP3。

支持 Windows 10/11 x64，需要 WebView2 Runtime。产物尚未代码签名，Windows SmartScreen 可能显示未知发布者。已完成自动化与样本音频验证，安装流程及内置播放器体验尚未进行人工验收。
